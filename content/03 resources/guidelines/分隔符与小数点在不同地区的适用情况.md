| 分隔符类型      | 符号       | 使用场景                 | 示例             |
|:--------- |:------- |:------------------- |:------------- |
| **小数点分隔符** | `.` (点号) | 美国、英国、澳大利亚、多数亚洲国家    | `123.45`       |
|            | `,` (逗号) | 欧洲大陆、拉丁美洲、部分非/亚洲国家   | `123,45`       |
| **千位分隔符**  | ` ` (空格) | ISO, SI              | `123 456 789`  |
|            | `,` (逗号) | 多数英语国家               | `123,456,789`  |
|            | `.` (点号) | 多数非英语国家 (即小数点用逗号的国家) | `123.456.789`  |
|            | `'` (撇号) | 瑞士 (货币)              | `123'456'789`  |
|            | (不固定)    | 印度计数系统 (2/3 位分组)     | `12,34,56,789` |
