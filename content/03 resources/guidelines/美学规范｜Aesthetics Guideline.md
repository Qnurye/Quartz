## 字体 | Fonts

| 场景      | 黑体                        | 衬线体                                          | 等宽                 |
| ------- | ------------------------- | -------------------------------------------- | ------------------ |
| UI      | "IBM Plex Sans SC"        | -                                            | -                  |
| Content | "Inter", "LXGW Neo Xihei" | "Baskervville", "GenRyuMin2 TC", "Songti SC" | "Maple Mono NF CN" |

- [IBM Plex Sans](https://www.ibm.com/plex/)：在我的刻板印象中，IBM 一直代表着极具历史感的低分辨率坚硬的工业线条。直到在 Zed 中用上，并爱上了这个保留理性，但意外地漂亮的字体。
- [Inter](https://rsms.me/inter/)：SF leaked.
- [霞鹜新晰黑](https://github.com/lxgw/LxgwNeoXiHei)：基于 IPAex 黑体，流畅的中文黑体。
- [Baskervville](https://anrt-nancy.fr/en/fonts/baskervville)：与源流明體很搭
- [源流明體](https://github.com/ButTaiwan/genryu-font)：线条非常美丽的汉字体。
- [Maple Mono NF CN](https://font.subf.dev/en/)：我的唯一指定 mono font。
